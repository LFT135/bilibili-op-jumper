# B站一键跳过番剧片头 (浏览器扩展版)

## 简介

这是一个可以在 Chrome / Edge 浏览器中直接安装的扩展程序，功能与原 Tampermonkey 用户脚本完全一致：

- 在 B站番剧播放页和视频页自动生效
- 支持自定义触发键位（默认 = / + 键）
- 支持自定义跳过时长（默认 90 秒）
- 右下角设置面板可实时调整

## 安装步骤

下载压缩包并解压，在浏览器中导入已解压的扩展程序文件夹。

### Chrome 浏览器

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 并回车
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件夹（包含 manifest.json 的目录）
5. 扩展安装完成，图标出现在浏览器右上角

### Edge 浏览器

1. 打开 Edge，地址栏输入 `edge://extensions/` 并回车
2. 左下角开启「开发人员模式」
3. 点击「添加或拖拽扩展」
4. 选择本文件夹（包含 manifest.json 的目录）
5. 扩展安装完成

## 使用方法

- 打开 B站番剧播放页面或视频页面
- 按下触发键（默认 = / + 键）即可跳过指定时长的片头
- 点击页面右下角的 齿轮 图标打开设置面板：
  - 点击「当前触发键」按钮后按下新按键可修改快捷键
  - 输入框可修改跳过时长（秒）
  - 点击「保存」按钮保存设置

## 文件说明

- manifest.json - 扩展配置文件（Manifest V3）
- content.js - 内容脚本（核心功能代码）
- icon16.png / icon48.png / icon128.png - 扩展图标（可选，建议添加）

## 注意事项

1. 本扩展仅在你访问 B站 的 bangumi/play 和 video 页面时生效
2. 设置数据保存在浏览器 localStorage 中，清除浏览器数据会重置配置
3. 如需更新扩展，在扩展管理页面点击「刷新」按钮即可
4. 建议自行添加扩展图标文件（icon16.png、icon48.png、icon128.png），否则浏览器可能显示默认图标
